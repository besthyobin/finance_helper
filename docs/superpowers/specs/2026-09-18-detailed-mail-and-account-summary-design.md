# 매매 알림 메일 상세화 및 웹 UI 계좌 총액 요약 설계

## 1. 개요 및 배경

현재 모의투자 시스템의 메일 알림과 웹 대시보드 UI에 대해 사용자가 제기한 두 가지 핵심 불편 사항을 개선합니다:
1. **메일 내용 부실**: 매수, 매도, 마감 메일이 단 1줄이거나 종목명/체결금액/진입단가/청산사유/계좌현황 등 필수 거래 정보가 누락되어 상황을 제대로 파악하기 어려움.
2. **UI 총액 부재**: 모의투자 웹 화면에 개별 종목의 상태만 표시될 뿐, "현재 내 총 자산이 얼마인지", "현금 잔고(예수금)는 얼마이고 주식 평가액은 얼마인지", "총 수익률은 몇 %인지" 전체 계좌 총액 요약이 표시되지 않음.

## 2. 세부 요구사항 및 기능 설계

### 1) 알림 메일 메시지 상세화 (`paper.py`)

#### A. 매수 체결 알림 (`_buy`)
- **제목**: `[모의투자] 매수 체결: 삼성전자(005930) 38주`
- **본문 구성**:
  ```text
  [모의투자] 매수 체결 안내

  ■ 종목: 삼성전자 (005930)
  ■ 체결 시각: 2026-09-18 09:32 (KST)
  ■ 체결 단가: 65,400원 (슬리피지 0.05% 반영)
  ■ 체결 수량: 38주
  ■ 매수 총액: 2,485,200원

  ■ 적용 정책
  - 운용 전략: ORB (시초가 돌파)
  - 손절 기준: -1.5% (예상 손절가: 약 64,419원)
  - 익절 기준: +2.0% (예상 익절가: 약 66,708원)

  ■ 계좌 현황
  - 종목 배정예산: 2,500,000원 중 2,485,200원 체결 (잔여 14,800원)
  ```

#### B. 매도/청산 체결 알림 (`_sell`)
- **제목**: `[모의투자] 매도 체결: 삼성전자(005930) 손익 +42,000원 (+1.69%)`
- **본문 구성**:
  ```text
  [모의투자] 매도 청산 안내

  ■ 종목: 삼성전자 (005930)
  ■ 청산 사유: 목표 익절 도달 (또는 손절선 도달 / 15:15 당일마감 강제청산)
  ■ 체결 내역
  - 매수 진입: 09:32 @ 65,400원 (38주, 총 2,485,200원)
  - 매도 청산: 10:15 @ 66,800원 (38주, 총 2,538,400원)
  - 보유 시간: 43분

  ■ 손익 결과
  - 실현 손익: +42,000원
  - 실현 수익률: +1.69% (수수료·세금·슬리피지 반영)

  ■ 당일 누적 거래 현황
  - 오늘 거래: 2건 중 2승 0패 (승률 100%)
  - 누적 실현손익: +75,000원
  ```

#### C. 장 마감 일일 요약 알림 (`summary`)
- **제목**: `[모의투자] 2026-09-18 마감 요약: 거래 3건, 실현손익 +65,000원 (+0.65%)`
- **본문 구성**:
  - 시작 자본금 대비 마감 총 자산 및 일일 총 수익률
  - 전체 거래 승/패 통계, 승률, 실현손익 합계
  - 종목별 세부 체결 리스트 (종목명, 진입시각/단가, 청산시각/단가, 청산사유, 손익, 수익률)
  - 실시간 체결 vs 백테스트 정합성 비교 결과

## 2. 웹 UI 현재 총액 및 계좌 요약 (Account Summary)

### A. 백엔드 API (`GET /api/account`)
- 계산 로직:
  - `capital`: 기본 자본금 (`os.environ["PAPER_CAPITAL"]`, 10,000,000원)
  - `realized_pnl`: 오늘 완료된 체결들의 실현손익 합계
  - `unrealized_pnl`: 현재 보유 중인 종목들의 평가손익 합계 (`eval_krw` 합계)
  - `stock_eval`: 현재 보유 주식의 시장 평가금액 합계 (`last_close * qty`)
  - `stock_cost`: 현재 보유 주식의 매수 원금 합계 (`entry_price * qty`)
  - `cash`: 현금 잔고 (`capital + realized_pnl - stock_cost`)
  - `total_assets`: 총 평가 자산 (`cash + stock_eval` = `capital + realized_pnl + unrealized_pnl`)
  - `total_pnl`: 오늘 총 손익 (`realized_pnl + unrealized_pnl`)
  - `return_pct`: 오늘 총 수익률 (`(total_pnl / capital) * 100`)

### B. 프론트엔드 UI 요약 카드 배치
- **위치**: 매매 정책 카드 바로 아래에 계좌 총액 요약 카드를 배치
- **주요 표시 항목**:
  1. **총 평가 자산**: `10,028,975원` (당일 손익 `+28,975원`, `+0.29%`)
  2. **예수금 (현금 잔고)**: `7,514,800원`
  3. **보유 주식 평가액**: `2,514,175원`
  4. **시작 원금**: `10,000,000원`
  5. **실현 손익**: `0원` / **평가 손익**: `+28,975원`
- 실시간 자동 동기화 (`refresh()` 주기 5초)
